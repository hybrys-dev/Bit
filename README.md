# Bit

A desktop companion for developers. One small character on your desktop drives all your coding agents
(Claude Code, Codex, OpenCode, Cursor, OpenClaw and Hermes, local or remote) and chats with any LLM API.

> **Status:** pre-alpha. Bit is built by AI agents in cloud sessions, behind automated checks.
> See [docs/ROADMAP.md](docs/ROADMAP.md).

## Why Bit

- **One cockpit:** pick agent, model, effort, mode, project and session from one place.
- **Every agent:** any agent that speaks the Agent Client Protocol works out of the box.
- **One inbox:** permission requests from every agent land in one place, answerable from the character's bubble.
- **Any model:** OpenAI-compatible, OpenAI Responses, Anthropic and Gemini APIs, custom endpoints and local models.
- **Local-first:** no Bit server, no telemetry, keys in your OS keychain.

## How this repository works

Issues, then cloud agents, then pull requests, then CI, security checks and AI review, then the merge queue.
Humans approve only changes to the guardrails. Rules for agents: [AGENTS.md](AGENTS.md).
Design: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

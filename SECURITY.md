# Security policy

Report vulnerabilities privately from the repository **Security** tab ("Report a vulnerability").
Please do not open public issues for security problems.

We aim to acknowledge reports within 7 days. Only the latest release receives fixes.

Areas of particular interest:

- the local core (`bitd`) and its IPC with the desktop shell;
- how agent permission requests are shown and answered;
- storage of API keys and tokens;
- remote connections (SSH, agent gateways);
- the update mechanism and release artifacts.

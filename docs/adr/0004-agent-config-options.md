# ADR 0004: Selectors from agent config options

## Status

Accepted

## Context

Bit does not keep its own model catalog for agents. This ADR records the decision in section 13 of [docs/ARCHITECTURE.md](../ARCHITECTURE.md).

## Decision

Selectors from agent config options.

## Rejected

- A catalog maintained by Bit

## Revisit when

A major agent exposes no config options.
